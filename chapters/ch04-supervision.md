# 第四章 安全生产的监督管理（第62-78条）

## Core Idea
本章规定监管部门的执法职权、程序约束与社会监督机制：分类分级监管、行政审批把关、现场检查四项职权、强制措施、举报与联合惩戒，同时约束监管行为本身（不得收费、不得指定产品、不得影响正常经营）。

## Frameworks Introduced
- **监管方式框架（第62条）**：县级以上政府按辖区状况组织严格检查；应急管理部门分类分级监管 + 制定并执行年度监督检查计划。
  - 何时用：判断企业被检查频次与方式的制度依据。
- **行政执法四项职权（第65条）**：①进入现场检查、调阅资料、了解情况；②当场纠正或限期改正、作出行政处罚决定；③责令立即排除隐患，重大隐患排除前无法保证安全的→撤出作业人员、责令暂时停产停业或停止使用相关设施设备，排除后经审查同意方可恢复；④对不符合国标/行标的设施设备器材及违法危险物品予以查封扣押，对违法作业场所予以查封。
  - 何时用：理解监管部门权力边界与企业配合义务时。
- **强制履行机制（第70条）**：对拒不执行停产停业等决定且有现实危险的，经本部门主要负责人批准，可通知有关单位停止供电、停止供应民用爆炸物品；书面通知；除紧急情形外提前24小时通知；企业履行后及时解除。
  - 何时用：企业面对停产决定时的法律后果评估。
- **失信联合惩戒体系（第78条）**：违法行为信息库 → 情节严重者向社会公告并通报多部门 → 联合惩戒措施（加大检查频次、暂停项目审批、上调保险费率、行业或职业禁入）→ 处罚决定后7个工作日内公示曝光。
  - 何时用：评估违法成本、应对信用惩戒。

## Key Concepts
- **审查批准**：包括批准、核准、许可、注册、认证、颁发证照等；不符合安全生产条件的不得批准或验收通过（第63条）。
- **撤销原批准**：已批准单位不再具备安全生产条件的，行政审批部门应撤销（第63条）。
- **监督检查人员义务**：出示有效行政执法证件、保守技术秘密和业务秘密（第67条）。
- **书面检查记录**：时间、地点、内容、发现的问题及处理情况，检查人员与被检查单位负责人签字（第68条）。
- **联合检查与移送**：能联合检查的联合检查；发现问题属其他部门的及时移送并记录备查（第69条）。
- **公益诉讼**：因安全生产违法行为造成重大事故隐患或重大事故、侵害国家利益或社会公共利益，检察院可提起公益诉讼（第74条）。

## Mental Models
- 审批是入口闸门：不符合条件不得批准/验收，发现擅自经营者立即取缔。
- 重大隐患处理阶梯：责令立即排除 → 无法保证安全则撤人/停产停业 → 排除后审查同意恢复。
- 执法程序约束：不得收取审查验收费用、不得指定产品、检查不得影响正常经营、须出示证件、须书面记录。
- 社会共治：任何单位或个人可举报；居委会村委会应报告；新闻媒体有舆论监督权。

## Anti-patterns
- **监管部门要求购买指定品牌设备或收取审查验收费用**：违法（第64条、第91条处罚）。
- **对企业停产决定拒不执行**：可能触发停止供电等强制措施（第70条）。
- **隐瞒事故、拖延处理重大隐患**：监管部门工作人员将受处分或追刑责（第90条）。
- **租借资质、挂靠、出具虚假报告**（安全评价/认证/检测/检验机构）：直接触犯第72条禁令和第92条重罚。

## Worked Example
**情景**：某企业被查出存在重大事故隐患，监管部门责令停产整顿。企业认为不影响生产、继续作业。监管部门评估认为有发生事故的现实危险。
**适用路径**：① 依第70条，监管部门经主要负责人批准可通知供电企业停止供电（书面形式）；② 若非紧急情形，须提前24小时通知企业；③ 企业依法履行决定、消除隐患后，监管部门应当及时解除措施；④ 企业拒不执行停产决定还可能触发第113条"提请政府关闭"和第112条按日连续处罚。

## Key Takeaways
1. 监管权限有清单（四项职权）也有边界（不得收费、不得影响正常经营、须出示证件）。
2. 重大隐患面前，撤人、停产、查封是法定手段，企业拒不执行将面临供电中断、按日连续处罚乃至关闭。
3. 违法行为信息将进入信用体系，联合惩戒（禁入、上调保费、暂停审批）是长期成本。
4. 中介机构结果真实性责任重大，出具虚假报告最高面临吊销资质、终身行业禁入。
