# 第二章 生产经营单位的安全生产保障（第20-51条）

## Core Idea
本章是主体责任的核心章节：规定生产经营单位必须满足安全生产条件，通过组织（机构人员）、投入、制度（双重预防）、行为（危险作业、设备、发包）四类保障措施落实安全生产。

## Frameworks Introduced
- **主要负责人七项职责（第21条）**：①建立落实全员安全生产责任制并加强标准化建设；②组织制定实施规章制度和操作规程；③组织制定实施教育培训计划；④保证安全投入有效实施；⑤组织建立落实双重预防机制、督促检查、消除隐患；⑥组织制定实施应急救援预案；⑦及时如实报告生产安全事故。
  - 何时用：检查主要负责人是否履职、划定"第一责任人"责任清单时。
- **机构与人员配置梯度（第24条）**：矿山、金属冶炼、建筑施工、运输、危险物品（生产/经营/储存/装卸）单位→必须设机构或专职安管人员；其他单位从业人员超100人→必须设机构或专职；100人以下→专职或兼职。
  - 何时用：判断企业是否需要设置安管机构/专职人员。
- **三同时制度（第31条）**：安全设施与主体工程同时设计、同时施工、同时投入生产和使用，安全设施投资纳入建设项目概算。
  - 何时用：新建、改建、扩建项目管理。
- **双重预防机制落地（第41条）**：风险分级管控制度（按风险分级采取管控措施）+ 隐患排查治理制度（技术管理措施、如实记录、向从业人员通报；重大隐患向监管部门报告）。
  - 何时用：建立企业日常安全管理核心流程。

## Key Concepts
- **安全生产条件**：本法、有关法律法规、国标或行标规定的条件；不具备的不得从事生产经营活动（第20条）。
- **安全生产费用**：按规定提取使用、专项用于改善安全生产条件、成本中据实列支（第23条）。
- **专职安全生产管理人员**：矿山等五类单位必须配备；其任免在危险物品生产储存、矿山、金属冶炼单位应告知监管部门（第24、26条）。
- **注册安全工程师**：危险物品生产储存装卸、矿山、金属冶炼单位应当有注册安全工程师从事安全管理（第27条）。
- **特种作业人员**：必须经专门培训取得相应资格方可上岗（第30条）。
- **重大危险源**：登记建档、定期检测评估监控、制定应急预案、告知应急措施、向政府备案（第40条）。
- **安全生产责任保险**：国家鼓励投保；国家规定的高危行业领域应当投保（第51条）。

## Mental Models
- 先问"是否具备安全生产条件"：不具备即不得经营——这是进入门槛。
- 教育培训是上岗前提：未经培训合格不得上岗；被派遣劳动者、实习学生同样纳入（第28条）。
- 危险作业要"专人现场管理"：爆破、吊装、动火、临时用电必须安排专门人员（第43条）。
- 检查闭环：安管人员检查→立即处理或报告负责人→负责人及时处理→如实记录；重大隐患负责人不及时处理的，安管人员可直接报监管部门（第46条）。
- 发包出租不甩责：发包给不具备条件/资质的单位个人即违法；发包方须统一协调管理、定期检查（第49条）。

## Anti-patterns
- **关闭破坏监控报警防护救生设备或篡改销毁数据**（第36条）：高压红线，直接触发第99条罚款。
- **车间商店仓库与员工宿舍同楼或距离不足、锁闭封堵疏散通道**（第42条）：直接触发第105条处罚。
- **使用应当淘汰的危及生产安全的工艺设备**（第38条）：禁止性规定，违反即罚。
- **不与交叉作业单位签安全管理协议**（第48条）：同一作业区域可能危及对方安全时必须签订协议并指定专职人员。
- **对安管人员依法履职降薪解雇**（第26条）：违法，且危险品等四类单位安管人员任免须告知监管部门。

## Worked Example
**情景**：某建筑施工企业（从业人员80人）发生事故，调查发现：未设专职安管人员、特种作业人员无证上岗、未建隐患排查治理台账。
**适用路径**：① 机构配置——建筑单位属第24条第1款必须设机构/专职安管人员的情形，80人规模不适用"100人以下可配兼职"；② 特种作业无证上岗违反第30条；③ 未建隐患排查治理制度违反第41条。责任链条：主要负责人未履行第21条第⑤项职责 → 依第94条责令限期改正并罚款；单位依第97条（机构、培训、特种作业持证）受罚。

## Key Takeaways
1. 主要负责人七项职责是"第一责任人"的法定清单，逐项对照自查。
2. 机构设置看行业属性（五类必设）和人员规模（100人线）两个维度。
3. 双重预防机制（风险分级管控+隐患排查治理）是日常管理的核心流程，必须记录、通报、报告。
4. 危险作业、特种作业、设备设施、发包出租各有专属红线，违反直接进入第六章罚则。
