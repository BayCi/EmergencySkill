# 第三章 从业人员的安全生产权利义务（第52-61条）

## Core Idea
本章界定从业人员在安全生产中的权利（知情、建议、批评检举控告、拒绝违章、紧急避险、赔偿）与义务（遵章守规、接受培训、报告隐患），并保障其行使权利不受打击报复。

## Frameworks Introduced
- **从业人员权利清单（第52-56条）**：①劳动合同载明劳动安全、防职业危害、工伤保险事项；②知情权（危险因素、防范措施、应急措施）；③建议权；④批评、检举、控告权；⑤拒绝违章指挥和强令冒险作业权；⑥紧急避险权（发现直接危及人身安全时可停止作业或撤离）；⑦工伤保险 + 民事赔偿。
  - 何时用：审查用工合规、处理劳资安全争议、设计安全教育内容时。
- **反报复保护框架（第53-55条）**：生产经营单位不得因从业人员批评、检举、控告、拒绝违章指挥、紧急撤离而降低工资福利待遇或解除劳动合同。
  - 何时用：判断企业处分行为是否违法；从业人员维权时的请求权基础。
- **从业人员义务三支柱（第57-59条）**：①落实岗位安全责任、遵章守规、服从管理、正确佩戴使用劳保用品；②接受教育培训；③发现事故隐患或不安全因素立即报告现场安管人员或负责人。
  - 何时用：界定从业人员自身违法/违规责任时（对应第107条）。

## Key Concepts
- **知情权**：了解作业场所和工作岗位的危险因素、防范措施及事故应急措施（第53条）。
- **紧急避险权**：发现直接危及人身安全的紧急情况，有权停止作业或采取可能应急措施后撤离（第55条）。
- **免责协议无效**：以任何形式订立协议免除或减轻单位对从业人员因生产安全事故伤亡应承担责任的，协议无效（第52条、第106条）。
- **被派遣劳动者**：享有本法规定的从业人员权利并履行义务（第61条）。
- **工会的从业者保护职能**：监督三同时、要求纠正侵权、建议撤离、参加事故调查（第60条）。

## Mental Models
- 权利与义务对称：从业人员既是保护对象（权利），也是责任主体（义务）——"严格岗位安全责任"是第57条的表述，违反则受第107条处分。
- 行使权利不担责：拒绝违章指挥、紧急撤离是法定权利，企业据此处分即违法。
- 工伤保险不排斥民事赔偿：工伤险之外的损害，依民事法律仍可索赔（第56条）——"工伤保险+民事补充"双轨。
- 报告隐患是法定义务：发现隐患不报告，从业人员自身可能承担违规责任。

## Anti-patterns
- **订立"生死状"协议**：免除或减轻对从业人员伤亡责任的协议无效，且对主要负责人、个人经营投资人处2万-10万元罚款（第106条）。
- **打击报复行使权利的从业人员**：降薪、解雇均违法；企业将承担相应法律责任。
- **从业人员违反操作规程**：批评教育、依规章制度处分，构成犯罪的追究刑事责任（第107条）。

## Worked Example
**情景**：工人小张发现车间可燃气体报警装置失灵，拒绝继续在危险区域作业并撤离，随后向应急管理部门检举。企业以"不服从管理"为由解除其劳动合同。
**适用路径**：① 小张发现的不安全因素属于第59条应立即报告的情形，其先行报告；② 撤离行为符合第55条紧急避险权；③ 企业解除劳动合同违反第54条反报复保护——不得因拒绝违章指挥、紧急撤离而解除合同；④ 小张可主张恢复劳动关系或赔偿，并可依第56条主张工伤险+民事赔偿。

## Key Takeaways
1. 从业者五大核心权利（知情、建议、检举控告、拒绝违章、紧急避险）与三项义务（守规、受训、报告）是对称的。
2. 任何形式的免责协议一律无效，企业主对此另受罚款。
3. 企业不得因从业者行使法定权利而报复，否则解雇决定违法。
4. 工伤险之外还可主张民事赔偿，损害救济是"双轨"的。
