# 第五章 生产安全事故的应急救援与调查处理（第79-89条）

## Core Idea
本章规定事故"前-中-后"全链条制度：事前应急预案与救援能力建设，事中报告与抢救，事后调查处理与整改评估，核心是"及时如实报告、立即组织抢救、科学调查追责、整改闭环评估"。

## Frameworks Introduced
- **三级应急预案体系（第80-81条）**：县级以上政府组织制定本行政区域预案 → 乡镇/街道/开发区等制定相应预案 → 生产经营单位制定本单位预案并与政府预案相衔接、定期组织演练。
  - 何时用：检查预案完备性与衔接性。
- **事故报告链条（第83-85条）**：现场人员立即报告本单位负责人 → 负责人迅速组织抢救、按国家规定立即如实报告当地负有监管职责的部门（不得隐瞒、谎报、迟报，不得破坏现场毁灭证据）→ 监管部门立即按规定上报 → 有关地方政府和监管部门负责人立即赶赴现场组织抢救。
  - 何时用：事故发生后各主体的响应流程与责任认定。
- **调查处理原则（第86条）**：科学严谨、依法依规、实事求是、注重实效；及时准确查清原因、查明性质责任、评估应急处置、总结教训、提出整改措施和处理建议；调查报告依法及时向社会公布。
  - 何时用：评价事故调查质量与程序。
- **整改闭环评估（第86条第2款）**：批复调查报告后一年内，组织评估整改和防范措施落实情况并公开；不履职致整改落空的追究责任。

## Key Concepts
- **应急救援组织（第82条）**：危险物品生产/经营/储存单位、矿山、金属冶炼、城市轨道交通运营、建筑施工等单位应建立应急救援组织；规模较小可不建但须指定兼职应急救援人员。
- **应急救援器材**：上述单位须配备必要的器材、设备、物资并经常性维护保养（第82条）。
- **责任事故（第87条）**：经调查确定为责任事故的，除追单位责任外，还应查明对安全生产事项负有审查批准和监督职责的行政部门的责任。
- **阻挠干涉禁令（第88条）**：任何单位和个人不得阻挠和干涉对事故的依法调查处理。
- **统计公布（第89条）**：县级以上政府应急管理部门定期统计分析本辖区事故情况并定期向社会公布。

## Mental Models
- 报告速度优先：现场人员→负责人→监管部门，链条即时传递，任何一环隐瞒谎报迟报都是独立违法。
- 抢救优先于追责：单位负责人立即组织抢救、不得擅离职守；政府负责人赶赴现场统一指挥。
- 追责双向：既查企业责任，也查审查批准和监督职责的行政部门责任（第87条）。
- 调查结论公开：调查报告向社会公布，整改评估结果公开——事故处理全流程透明化。

## Anti-patterns
- **隐瞒不报、谎报、迟报**：单位负责人（第83条）、监管部门与地方政府（第84条）均禁止，违者按第110、111条处罚。
- **故意破坏事故现场、毁灭证据**：明确禁止（第83条）。
- **单位负责人在事故调查处理期间擅离职守或逃匿**：触发第110条（降级撤职、罚款、拘留）。
- **阻挠干涉事故调查**：任何单位和个人不得为之（第88条）。
- **整改措施不落实**：一年内评估将追责不履职人员（第86条）。

## Worked Example
**情景**：某化工厂发生泄漏事故，值班员立即报告厂长，厂长未上报应急管理部门，也未组织疏散，连夜清理现场。次日应急管理部门接举报介入调查。
**适用路径**：① 厂长违反第83条——接到报告后应迅速组织抢救并立即如实报告，其隐瞒迟报且破坏现场（清理毁灭证据）；② 依第110条对主要负责人处上一年年收入60%-100%罚款，逃匿/瞒报情形另处拘留；③ 若调查认定属责任事故，依第87条同时查明负有审查批准和监督职责部门的责任；④ 事故调查报告公开，一年内评估整改落实。

## Key Takeaways
1. 事故报告链条四环（现场人员→负责人→监管部门→上级）必须即时如实，隐瞒谎报迟报均属违法。
2. 单位负责人事故中的核心义务：立即组织抢救、不得擅离职守、不得破坏现场。
3. 调查处理坚持四原则，报告公开，整改一年内评估——事故处理有明确时间与公开要求。
4. 责任事故追责是双向的：企业责任 + 审查批准和监督部门的失职责任。
